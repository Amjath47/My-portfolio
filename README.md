## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Amjath47/portfolio-website.git
```

Navigate to the project folder:

```bash
cd portfolio-website
```

Open the website:

```bash
index.html
```

or use VS Code Live Server.

---

## 🚀 Deployment

### GitHub Pages

1. Push the project to GitHub.
2. Go to:

```text
Settings → Pages
```

3. Select:

```text
Deploy from Branch → main → /(root)
```

4. Save changes.

Your site will be available at:

```text
https://amjath47.github.io/portfolio-website/
```
